# Package `operacional`

Agenda, clientes e disponibilidade no painel. Fluxo: Component → Hook → Service → Data → API.

Entidades: `Customer`, `Appointment`, `Availability`. Tipos HTTP vêm de `@repo/contracts`.

UI de clientes (S3 Bloco 2): `/clientes` e `/clientes/[id]`.
UI de agenda (S3 Bloco 3): `/` (dia) e `/agenda` (semana).
